This API and every book in it are fictional test data. A live API server has not yet been provisioned.

The API has two endpoints:

- `GET /books` returns an array of books.
- `GET /books/{id}` returns a book with `id`, `title`, `author_name`, and `published_year`.

For book `1`, the expected response is:

```json
{"id": 1, "title": "The Sample Book", "author_name": "Alex Example", "published_year": 2024}
```

See [Authentication](/bookstore/authentication) and [Endpoints](/bookstore/endpoints).
